# Gradeculator v1.8 — Calculator + GPA Sandbox (ต่อจาก v1.7)

เวอร์ชันนี้เปลี่ยนเมนู **Destination → Calculator** โดย **คงระบบคำนวณ GPA เป้าหมายเดิมไว้ทั้งหมด** และเพิ่มส่วน **ทดลองคำนวณ GPA รายวิชา** แยกจาก Courses และ Dashboard

- กรอกชื่อวิชา, หน่วยกิต และคะแนน (เต็ม 100) โดยเพิ่ม/ลบรายการได้
- ใช้เกณฑ์มาตรฐาน Gradeculator A=80, B+=75, B=70, C+=65, C=60, D+=55, D=50, F<50 และคำนวณ GPA แบบถ่วงน้ำหนักหน่วยกิต
- แถวที่กรอกไม่ครบหรือไม่ผ่านการตรวจข้อมูลจะไม่นำไปคำนวณ (แสดงจำนวนวิชาที่นำมาคิด)
- ปุ่ม **ล้างข้อมูล** อยู่มุมล่างขวา พร้อมหน้าต่างยืนยัน ล้างเฉพาะวิชาทดลอง ไม่แตะ Courses
- ข้อมูล Calculator จะ **บันทึกอัตโนมัติ** ใน Guest บน LocalStorage และเป็นส่วนหนึ่งของ Cloud document เมื่อ Login (หลังเชื่อม Supabase ตาม `SETUP_LOGIN.md` แล้ว)
- หากมีข้อมูลทดลองใน Guest ก่อน Login ระบบจะย้ายขึ้นบัญชีโดยอัตโนมัติ และพยายามรักษารายการของฝั่งออนไลน์ไว้ด้วย
- ใช้คีย์ LocalStorage เดิม `gradehub.mobile.v1`; JSON backup จากเวอร์ชันเก่าที่ยังไม่มี Calculator ก็เปิดได้

**สำคัญ:** ตัว Calculator นี้เป็นพื้นที่ทดลองเท่านั้น ไม่เพิ่มรายวิชา ไม่เปลี่ยน GPA จริง และไม่เปลี่ยนการคำนวณเป้าหมาย GPA เดิม

**การอัปเดตเว็บไซต์:** อ่าน [`UPDATE_GITHUB_PAGES.md`](UPDATE_GITHUB_PAGES.md) ก่อนอัปโหลดเข้า GitHub ของมึง

**การทดสอบ:** `npm test` ผ่าน 46 กรณี และตรวจไวยากรณ์ JSX/JS/CSS ผ่าน แต่เครื่องทดสอบไม่สามารถติดตั้ง dependencies จาก npm จึงยังไม่ได้ทดสอบ Build/การแสดงผลในเบราว์เซอร์จริง

# Gradeculator — Mobile-ready Web App (v1.5)

Gradeculator ตัวใหม่ที่ออกแบบหน้าตาตามภาพตัวอย่างของโปรเจกต์เดิม แต่เขียนระบบใหม่ด้วย **React + JavaScript + CSS** ไม่ต้องรัน Python/Flask และยังไม่มีเซิร์ฟเวอร์ฐานข้อมูล

## ความสามารถ

- Splash Screen 2 วินาทีเมื่อเปิดแอป
- Dashboard: GPA สะสมและ GPA แยกรายเทอม, หน่วยกิต, ผ่าน / ตก (ปรับเลย์เอาต์ 4 การ์ดบนจอกว้างและแถบความคืบหน้า)
- Courses: เพิ่มปีและเทอม, ตั้งสถานะเทอม (เรียนจบ / กำลังเรียน / อนาคต), จัดรายวิชาในโฟลเดอร์ยุบ-ขยายได้ พร้อม **จำสถานะยุบ/ขยายทั้งปีและเทอม** แม้เปลี่ยนหน้าหรือปิดแล้วเปิดใหม่ (และติดไปกับไฟล์สำรอง JSON)
- เพิ่ม/แก้ไข/ลบวิชา กรอกชื่อ รหัส หน่วยกิต คะแนนเต็ม และเกณฑ์ตัดเกรดแต่ละวิชา
- คะแนนเก็บย่อยแบบ `คะแนนที่ได้ / คะแนนเต็ม` (ตัวเลขจะแสดงสีเมื่อมีคะแนนแล้ว) เลือกแสดงตัวเลขเขียวหรือแดง แก้ไขได้ **ลากที่ไอคอน Grip เพื่อสลับลำดับคะแนนเก็บได้ทั้งจอสัมผัสและเมาส์** (หรือโฟกัสที่ไอคอนแล้วใช้ลูกศรขึ้น/ลง)
- เกรด A, B+, B, C+, C, D+, D, F ตามคะแนนขั้นต่ำ **80,75,70,65,60,55,50,0 คะแนนจริง (ไม่ใช่เปอร์เซ็นต์)** เปลี่ยนได้เป็นรายวิชา เช่น วิชาเต็ม 120 คะแนน ได้ 80 คะแนนจะเป็น A
- เลือกวิธีตัดเกรดได้ **3 แบบที่แยกจากกัน**: อัตโนมัติตามคะแนน / กำหนดเกรดเอง / อิงกลุ่ม (รอประกาศเกรดจริง)
- วิชาอิงกลุ่ม: บันทึกเกณฑ์ A และ F ที่คาดไว้, GPA เฉลี่ยของห้อง และสถิติ **Midterm / Final** อย่างละ 6 ค่า (Mean, Median, SD, Min, Max, N) แยกจากคะแนนเก็บ; ข้อมูลเหล่านี้ไม่เปลี่ยน GPA จนเลือกเกรดที่ประกาศแล้ว
- Destination: กรอก GPA เป้าหมาย เลือกปี/เทอมอนาคต กำหนดหน่วยกิตประมาณการ 18–25/เทอม พร้อมสรุปความเป็นไปได้ภายใต้หลักสูตร 129 หน่วยกิต
- บันทึกอัตโนมัติด้วย `localStorage` ในเบราว์เซอร์เดียวกัน และมี **สำรองข้อมูล / กู้คืนข้อมูล JSON**
- ออกแบบให้ responsive ทั้งหน้าจอคอมและโทรศัพท์ โดยปุ่มเพิ่มเทอม/แก้ไข/ลบปีอยู่แถวเดียวกัน
- โลโก้ Gradeculator รูปหมวกสีขาวบนพื้นน้ำเงิน และตั้งฟอนต์ **Kanit** (ดึงจาก Google Fonts เมื่อมีอินเทอร์เน็ต)

## การเก็บข้อมูลสำคัญมาก

ตอนนี้เวอร์ชันแรกสำหรับทดสอบบนคอมใช้ **localStorage** (ภายใน origin และ browser profile นั้น ๆ) ข้อมูลไม่ถูกส่งไปเซิร์ฟเวอร์ การปิดแท็บหรือรีสตาร์ตเบราว์เซอร์ปกติยังมีข้อมูล แต่ **ล้าง site data, ใช้โหมดส่วนตัว, เปลี่ยน browser/origin หรือถอนการติดตั้งแอปอาจทำให้ข้อมูลหาย**

ควรกดปุ่ม **ดาวน์โหลดไฟล์สำรอง JSON** (ไอคอนดาวน์โหลดที่แถบด้านบน) เป็นประจำ เมื่อต้องการย้ายข้อมูลระหว่างเครื่องให้กด **นำเข้าข้อมูล** (ไอคอนอัปโหลด) และยืนยันแทนที่ข้อมูลเดิม

ก่อนนำไปทำ APK จริง แนะนำให้เปลี่ยน storage adapter ใน `src/lib/storage.js` เป็น Capacitor SQLite และทดสอบการย้ายข้อมูลจากเว็บเดิมก่อน เพื่อให้เก็บข้อมูลไว้ในฐานข้อมูลของแอป และเพิ่ม backup/restore โดยยังคง schema เดิมได้

## หลักคำนวณ

- GPA = ผลรวม `(หน่วยกิตวิชา × แต้มเกรดวิชา) / หน่วยกิตวิชาที่ได้เกรด` และรวม F ในตัวหาร
- วิชายังไม่สรุปเกรดไม่ถูกนับใน GPA
- เกรดอัตโนมัติจะสรุปเมื่อเพิ่มรายการคะแนนเก็บครบคะแนนเต็มวิชา และกรอกคะแนนได้ครบทุกส่วน (คะแนน Bonus ไม่นับเป็นคะแนนจัดสรร และไม่บังคับกรอกเพื่อสรุปเกรด)
- เกรดแบบกำหนดเองจะถูกนำมาคิด GPA ได้ทันที ส่วน **เกรดอิงกลุ่ม** จะยังคงสถานะรอเกรดจนกว่าจะเลือกเกรดที่อาจารย์ประกาศจริง
- ค่าสถิติห้อง/คะแนนประมาณการ A และ F/GPA เฉลี่ยห้อง **ไม่ใช่สูตรตัดเกรดที่แน่นอน** และไม่นำมาใช้คำนวณเกรดอัตโนมัติ
- สีเขียว/แดงของช่องคะแนนเป็นสัญลักษณ์ตกแต่ง **ไม่ส่งผลต่อ GPA**
- Destination เป็นการประมาณการตามหน่วยกิตที่วางแผนและสมมติฐาน 18–25 หน่วยกิต ไม่สามารถทำนายเกรดจริงได้ และยังไม่รองรับนโยบายเรียนซ้ำที่อาจแตกต่างกันตามหลักสูตร
- หากยังไม่กำหนดสถานะเทอมปัจจุบัน/เรียนจบ ระบบจะถือว่าเทอมทั้งหมดเป็นเทอมในอนาคตจนกว่าจะกำหนดสถานะเอง

- เอากล่องสถานะปัจจุบันที่ซ้ำซ้อนใน Destination ออก แต่ข้อมูลการคำนวณและการประมาณหน่วยกิตยังครบ
- ไม่เปลี่ยนรูปแบบข้อมูลสำรองหรือคีย์ localStorage (`gradehub.mobile.v1`)

หากมีข้อมูลเก่า โปรดสำรองเป็น JSON ก่อนอัปเดต และเปิดด้วย origin เดิม


## สิ่งที่เปลี่ยนใน v1.3 (จาก PDF หมายเหตุล่าสุด)

1. เพิ่ม **อิงกลุ่ม** เป็นวิธีตัดเกรดตัวที่สาม แยกจากตัวเลือก **กำหนดเกรดเอง** เดิม
2. ในตัวแก้ไขวิชาอิงกลุ่ม ระบุคะแนนที่คาดว่าจะเริ่มได้ A, เกณฑ์ F โดยประมาณ, GPA เฉลี่ยห้อง (เช่น อาจารย์แจ้ง 2.85), และเกรดจริงที่ประกาศได้ โดยปล่อยช่องเกรดจริงว่างเพื่อเก็บสถานะ **รอเกรด**
3. ในหน้ารายวิชาอิงกลุ่ม มีช่องกรอกสถิติของ **Midterm** และ **Final** แยกกัน โดยแต่ละรายการมี Mean / Median / SD / Min / Max / N ที่แก้ไขและบันทึกได้ ข้อมูลสถิติไม่เพิ่มคะแนนและไม่กระทบ GPA
4. เอาปุ่ม **เพิ่มรายการคะแนน** ที่ซ้ำกับปุ่มด้านบนออกเมื่อรายการว่าง
5. เปลี่ยนหมายเลขหน้าคะแนนเป็นไอคอน **ลากเพื่อสลับลำดับ** และรองรับคีย์บอร์ดลูกศรขึ้น/ลงด้วย
6. เปลี่ยนหน้า Splash ให้ใช้โลโก้หมวกขาวบนวงกลมน้ำเงินเช่นเดียวกับ Header ลดขนาดตัวอักษรต้อนรับ และลดข้อความประกอบในหน้า Dashboard
7. เปลี่ยนผล Destination จากการ์ดพื้นดำเป็นพื้น **สีขาว** และปรับผังให้ผลลัพธ์ GPA ที่ต้องทำอยู่เคียงกับ GPA ปัจจุบัน/เป้าหมายบนหน้าจอกว้าง

**ข้อมูลจาก v1.0–v1.2 ใช้ต่อได้:** คง `version: 1` ในไฟล์ JSON และใช้ storage key `gradehub.mobile.v1` เดิม เพิ่มเฉพาะฟิลด์ที่ไม่บังคับ ไม่แก้ไขข้อมูลเดิมเมื่อโหลด

### ข้อจำกัดการทดสอบในชุดนี้

ชุดทดสอบ Node.js และการตรวจไวยากรณ์ JSX/CSS ผ่านแล้ว แต่เครื่องสร้าง ZIP ติดขัดในการดาวน์โหลด dependencies จาก npm จึงยังไม่สามารถยืนยันการ build ด้วย Vite หรือทดสอบภาพหน้าจอในเบราว์เซอร์จริงได้ โปรดใช้ `npm install`, `npm run dev` และ `npm run build` บนคอมก่อนนำไปแปลงเป็น APK

## สิ่งที่เปลี่ยนใน v1.5 (PDF ล่าสุด)

1. **แก้บัคเกณฑ์ตัดเกรดเต็ม 120 คะแนน:** เลขเกณฑ์คือคะแนนจริง ไม่ใช่เปอร์เซ็นต์; ตัวอย่าง A ขั้นต่ำ 80/120 ได้ A ทันทีที่คะแนนย่อยหลักครบและสรุปได้ (ก่อนหน้านี้จะคูณ 0.8 × 120 = 96 โดยผิดความต้องการ)
2. หน้าตั้งค่าเกณฑ์แก้ label เป็น **คะแนนขั้นต่ำ (คะแนน)** และหน้าเกณฑ์แสดงช่วงคะแนนจริง เช่น A 80–120, B+ 75–79.99
3. เพิ่มขนาดตัวเลข 4 ช่องใน Dashboard รายเทอม และ **คืนคอลัมน์เกรด** ในตารางรายวิชา Courses (มีป้ายรอเกรดสำหรับวิชาที่ยังไม่สรุป)
4. เปลี่ยน Bonus จากกล่องแยกด้านล่างเป็น **แถวรายการคะแนน** กดปุ่ม **+ Bonus** แล้วกรอก *รายละเอียดโบนัส* เช่น `+1+2` และ *คะแนนโบนัสที่ได้จริง* เช่น `5` ในแถวเดียวกับ Midterm/Final, ลากสลับลำดับได้ และลบได้
5. **คะแนน Bonus ไม่กินคะแนนเต็มที่จัดสรร** เช่น Midterm 30 + Final 90 = 120 คะแนนเต็ม และ Bonus +5 = คะแนนพิเศษที่ใช้เพิ่มคะแนนรวม; เมื่อคิดเกรดจะตัดคะแนนรวมไม่ให้เกินเพดานคะแนนเต็ม
6. ปรับ Popup ยืนยันลบให้กะทัดรัดขึ้นและจัดปุ่มยกเลิก/ลบข้อมูลใกล้ข้อความตามภาพ
7. ยังคง `gradehub.mobile.v1` เป็นคีย์ข้อมูลเดิม และเมื่อเปิด **ข้อมูล v1.4 ที่มี Bonus เดิม** จะย้ายรายละเอียดกับคะแนนโบนัสเดิมมาเป็นแถว Bonus ใหม่โดยอัตโนมัติ ไม่บวกซ้ำ และไม่เปลี่ยนคะแนนย่อยหลัก

**คำเตือนสำคัญ:** การเปลี่ยนจากเกณฑ์เปอร์เซ็นต์เป็นเกณฑ์คะแนนดิบอาจเปลี่ยนเกรดของวิชาที่มีคะแนนเต็มไม่เท่ากับ 100 และสรุปเกรดแล้ว โดยเฉพาะเมื่อคะแนนเต็ม 120 ขึ้นไป ให้ตรวจเกรดกับเกณฑ์ที่ต้องการหลังอัปเดต และกดสำรอง JSON จาก v1.4 ก่อนเสมอ

**วิธีอัปเดต:** สำรองไฟล์ JSON ก่อน แล้วคัดลอกโปรเจกต์ใหม่นี้ไปแทนไฟล์เดิม และเปิดเว็บด้วย **URL และเบราว์เซอร์เดิม** (`http://127.0.0.1:5173/`) เพื่อให้ข้อมูล LocalStorage เดิมยังคงอยู่ หากไม่เห็นข้อมูลเก่า ให้นำเข้า JSON ที่สำรองไว้
